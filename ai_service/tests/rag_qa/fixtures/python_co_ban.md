# Bài giảng: Lập trình Python cơ bản

## Chương 1. Biến và kiểu dữ liệu
Biến trong Python là tên dùng để tham chiếu tới một giá trị trong bộ nhớ. Python là ngôn ngữ kiểu động, nghĩa là không cần khai báo kiểu dữ liệu trước khi gán giá trị cho biến.
Các kiểu dữ liệu cơ bản gồm: int (số nguyên), float (số thực), str (chuỗi ký tự), bool (True/False).
Ví dụ: x = 5 tạo biến x kiểu int; ten = "An" tạo biến kiểu str.

## Chương 2. Cấu trúc điều khiển
Câu lệnh if dùng để rẽ nhánh theo điều kiện. Vòng lặp for dùng để duyệt qua các phần tử của một dãy, còn vòng lặp while lặp lại khi điều kiện còn đúng.
Lệnh break dùng để thoát khỏi vòng lặp ngay lập tức, lệnh continue bỏ qua phần còn lại của lần lặp hiện tại.

## Chương 3. Danh sách và từ điển
List (danh sách) là tập hợp có thứ tự, có thể thay đổi, viết trong dấu ngoặc vuông, ví dụ [1, 2, 3].
Tuple giống list nhưng không thể thay đổi (immutable), viết trong ngoặc tròn.
Dictionary (từ điển) lưu dữ liệu dạng cặp khóa - giá trị, ví dụ {"ten": "An", "tuoi": 20}. Truy cập giá trị bằng khóa: d["ten"].

## Chương 4. Hàm
Hàm được định nghĩa bằng từ khóa def. Hàm giúp tái sử dụng mã và chia chương trình thành các phần nhỏ.
Tham số mặc định cho phép gọi hàm mà không cần truyền đủ đối số. Lệnh return trả kết quả về cho nơi gọi hàm.
