# Local Risk Predictor (`local_risk_predictor`)

The `local_risk_predictor` plugin integrates with Smart-LMS to evaluate and identify students at risk of academic underperformance or dropout by extracting learning engagement metrics and feeding predictive models.

---

## Synthetic Analytics Testbed CLI

For local development, model prototyping, and evaluation pipelines, the plugin provides CLI scripts to generate realistic synthetic student interaction data directly in Moodle's PostgreSQL database.

### File Locations
- **Seeder**: `moodle/public/local/risk_predictor/cli/seed_analytics.php`
- **Cleaner**: `moodle/public/local/risk_predictor/cli/clean_analytics.php`

---

## Usage

### 1. Seeding Synthetic Analytics Data

Run from the Smart-LMS project root:

```bash
# Default setup (15 students, 2 courses)
php moodle/public/local/risk_predictor/cli/seed_analytics.php --students=15 --courses=2

# Custom prefix and capacity
php moodle/public/local/risk_predictor/cli/seed_analytics.php --students=30 --courses=3 --prefix=TEST
```

#### CLI Options
| Option | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `-h`, `--help` | flag | `false` | Display help and usage information. |
| `--students` | integer | `15` | Total synthetic students to create (partitioned equally across 3 profiles). |
| `--courses` | integer | `2` | Number of synthetic historical test courses to create. |
| `--prefix` | string | `AISEED` | Prefix applied to student usernames and course shortnames. |
| `--categoryid` | integer | `1` | Target Moodle course category ID. |

---

## Synthetic Student Profiles (Ground-Truth Archetypes)

Students generated by the seeder are partitioned into 3 distinct behavioral archetypes:

| Profile | Partition (N=15) | Course Access (Logs) | Assignment Submissions | Grade Range | Activity Completion |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Safe** | 5 students (`001` - `005`) | ~25 views spread evenly across the term | 100% (3/3 assignments) | 80 - 100 | All 3 activities marked complete |
| **Borderline** | 5 students (`006` - `010`) | ~10 views declining over time | ~66% (2/3 assignments) | 45 - 60 | 2 completed, 1 missing |
| **At-Risk** | 5 students (`011` - `015`) | ~3 views; completely disengages after weeks 2-3 | <33% (1/3 assignments) | 20 - 35 | 1 completed with low score, 2 missing |

---

## Cleanup Script

To reset the database and safely delete all synthetic entities without affecting production or default Moodle courses:

```bash
php moodle/public/local/risk_predictor/cli/clean_analytics.php [--prefix=AISEED]
```

This cleans up:
- Synthetic course records (`mdl_course`) and enrolments.
- Synthetic user accounts (`mdl_user`).
- Generated assignment activities, grade items, and grade grades.
- Generated standard logstore events.

## Verification Steps (Moodle Web UI)

1. Start your local Moodle server:
   ```bash
   php -S localhost:8000 -t moodle/public
   ```
2. Log in as Administrator at `http://localhost:8000`.
3. **Users**: Navigate to *Site administration > Users > Accounts > Browse list of users*. Confirm `aiseed_student_001` through `aiseed_student_015` are present.
4. **Courses**: Access `AISEED_COURSE_1` and verify the 3 assignments appear with completion criteria enabled.
5. **Gradebook**: Open the course **Grades** view and verify that the 3 student archetypes display their expected high, borderline, and failing grade distributions.
